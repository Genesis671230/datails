## What was built

### Endpoints

| Route | Notes |
|---|---|
| `GET /api/v1/health` | Only unauthenticated route (LD-1); liveness + non-fatal DB indicator |
| `POST /api/v1/workspaces/bootstrap` | The only provisioning path: tenant → owner user → default workspace → onboarding session → baseline methodology seed; idempotent per oid |
| `GET /api/v1/workspaces/me` | Current tenant context from the validated token |

OpenAPI contract exported to `docs/openapi.json` (LD-26); regenerated in CI as
an artifact.

### Schema (one migration, `34d139306e73`)

28 tables, 25 PostgreSQL enum types — the full Slice-0 core schema from
07_BUILD_PLAN: tenancy (tenants incl. `learning_capture_enabled` /
`credit_limit_usd` / `region`, users, workspaces, onboarding_sessions),
methodology (methodologies, methodology_steps, generated_templates incl.
`jurisdiction_variants_json`, workflow_agent_profiles), case domain (cases,
evidence_items, findings, decisions), wallets (workspace-global wallets,
case_wallets join, wallet_labels with `data_ledger_id` provenance FK),
connectors (+credential_owner) and connector_runs, traces + trace_hops,
ledgers (data_ledger, decision_ledger, ai_call_log, learning_events),
idempotency_keys, usage_records, tenant_plan_state, workflow_agents +
workflow_agent_runs.

LD-3 enforcement lives in the same migration: the runtime role
(`datails_app`) receives INSERT+SELECT only on the four append-only tables,
and triggers reject UPDATE/DELETE for any role. The migration fails loudly if
the restricted role does not exist.

### Auth (LD-1)

Entra External ID JWT validation middleware on every route except health:
signature (JWKS), issuer, audience, expiry. Tenant context derives only from
the validated `oid`. `AUTH_DEV_MODE=true` bypass exists for local development
only — configuration hard-fails outside `ENVIRONMENT=local`.

## Notes / environment quirks

- The repo volume creates macOS AppleDouble (`._*`) files that break Docker
  build context and Alembic's version scanning; `.dockerignore` covers Docker,
  and stray files are deleted before builds. If Alembic ever reports "source
  code string cannot contain null bytes", run:
  `find . -name '._*' -not -path './backend/.venv/*' -delete`
- `cryptography` is pinned to 44.0.0 (newest wheels don't cover macOS x86_64).
